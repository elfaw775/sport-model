## 3. 用模型做预测（推理）

### 3.1 单张图片

```bash
yolo detect predict \
    model=runs/horse/lesion_yolo11s_freeze10/weights/best.pt \
    source="骨折x线片（总）/1-RF-正位.jpg" \
    imgsz=640 \
    conf=0.1 \
    device=mps
```

### 3.2 整个文件夹（批量）

```bash
yolo detect predict \
    model=runs/horse/lesion_yolo11s_freeze10/weights/best.pt \
    source="某个新文件夹/" \
    imgsz=640 conf=0.1 device=mps \
    save=True save_txt=True save_conf=True
```

- `save=True`：保存画了框的图片
- `save_txt=True`：保存 YOLO 格式的框坐标（每个图一个 txt）
- `save_conf=True`：txt 里带上置信度分数

### 3.3 结果输出位置

默认在 `runs/detect/predict/`、`runs/detect/predict2/`……（每次递增，不会覆盖）。

```
runs/detect/predict/
├── 1-RF-正位.jpg          # 画好框的图
└── labels/1-RF-正位.txt   # 框坐标 + 置信度
```

> 想固定输出目录：加 `project=outputs name=test1`，结果就在 `outputs/test1/`。

## 4. 结果怎么读

### 4.1 看图

直接打开 `runs/detect/predict/` 里的 jpg，框上会标 `lesion 0.87`（类别 + 置信度）。

### 4.2 看 txt（要精确数值时）

`save_txt=True` 后每个图的 txt 长这样（YOLO 格式 + 置信度）：

```
0 0.322095 0.325751 0.252891 0.566116 0.87
```

含义：`类别id x中心 y中心 宽 高 置信度`，坐标是 0~1 归一化的。

换算成像素（以 377×672 的图为例）：`x_px = 0.322095*377`。

## 5. 调置信度阈值 `conf`

| conf | 效果 |
|---|---|
| 0.10 | 报得最多，最不容易漏，但误报多 |
| **0.25** | 默认，平衡 |
| 0.50 | 只报比较确定的，误报少但可能漏 |

医疗场景建议**先低阈值（0.10~0.25）保召回**，宁可多报给人复核，不要漏。

---

## 6. 怎么判断「这匹马有没有病变」

模型输出的是**框**，不是「有/无」结论。最简单实用的规则：

> 只要图里有 ≥1 个 `病变` 框且 `conf ≥ 阈值`，就判「疑似病变，建议人工复核」。

想批量自动出结论，可以用一个小脚本（需要时找我要，或参考 `predict.py`）逐图统计。

## 8. 常见问题

- **`device=mps` 报错** → 改成 `device=cpu`（会慢一些，但 68 张图也能跑）。
- **`torch.backends.mps.is_available()` 为 False** → 重装 torch：`.venv/bin/pip install --force-reinstall torch torchvision`。
- **找不到图片 / 中文路径** → 用绝对路径调 `data=...`，路径加引号。
- **内存/显存不够（OOM）** → `batch=8`、`imgsz=512`。
- **`yolo` 命令找不到** → 先 `source .venv/bin/activate`，或用 `.venv/bin/yolo`。

---

## 9. 模型局限（务必心里有数）

1. 训练集 **只有骨折片、没有正常片** → 对正常 X 光片很可能也会报框，**不能直接当「无病变」结论用**。
2. 68 张样本少，指标会虚高，泛化能力有限。
3. 建议把它当「辅助提示/初筛」，最终由兽医人工确认。
